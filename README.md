# Ecomemerce_store_Dashboard_PowerBI
# ECOMMERCE SALES DASHBOARD

## Power BI Business Intelligence Project Report

---

## 1. Executive Summary

The **Ecommerce Sales Dashboard** is a Business Intelligence project developed in Microsoft Power BI to analyze ecommerce sales and profitability data.

The project converts transactional ecommerce data into an interactive dashboard containing key performance indicators and multiple analytical visualizations. The dashboard enables users to examine sales amount, quantity, profit, Average Order Value, monthly profitability, product sub-categories, categories, payment modes, customers, and geographical performance.

Interactive Quarter and State filters allow users to perform focused analysis and investigate business performance from different perspectives.

---

## 2. Project Background

Ecommerce businesses generate large volumes of transactional data involving customers, products, orders, payment methods, locations, sales amounts, quantities, and profits.

Raw transactional data can be difficult to interpret directly. A Business Intelligence dashboard provides a visual interface through which decision-makers can monitor performance and identify important patterns.

This project addresses that requirement by developing an interactive ecommerce sales dashboard in Power BI.

---

## 3. Project Objectives

The primary objectives were:

1. Develop an interactive ecommerce sales dashboard.
2. Track important sales and profitability KPIs.
3. Analyze monthly profit trends.
4. Analyze product categories and sub-categories.
5. Examine customer-level sales performance.
6. Analyze state-wise sales performance.
7. Understand payment-mode distribution.
8. Provide interactive filtering capabilities.
9. Convert transactional data into business-friendly visual insights.

---

## 4. Technology Used

### Microsoft Power BI

Power BI was used as the primary Business Intelligence and visualization platform.

### Power Query

Power Query is used within the Power BI environment for data preparation and transformation.

### DAX

DAX-based aggregation and analytical calculations support dashboard KPIs and measures.

### Data Modeling

The dashboard uses the `Orders` and `Details` tables as its core analytical data structures.

---

## 5. Data Structure

The Power BI report references two primary tables:

### Orders

The dashboard uses fields from the Orders table including:

* Order Date
* State
* Customer Name

The Order Date field is used for time-based analysis and quarter/month filtering.

### Details

The Details table provides analytical fields including:

* Amount
* Quantity
* Profit
* AOV
* Category
* Sub-Category
* PaymentMode

Together, these fields support the dashboard's sales, profitability, customer, product, and payment analysis.

---

## 6. Dashboard Design

The dashboard follows an executive-style reporting layout.

### KPI Cards

Four primary KPI cards provide an overview of:

* Total Amount
* Total Quantity
* Total Profit
* Average Order Value (AOV)

These metrics allow users to understand the overall business performance before moving into detailed analysis.

---

## 7. Visualizations

### 7.1 Profit by Month

A column chart presents profit across months.

This visualization helps users identify changes in profitability over time and investigate periods with relatively higher or lower profit.

---

### 7.2 Profit by Sub-Category

A bar chart compares profit generated by different product sub-categories.

This analysis can help identify which product segments contribute more significantly to profitability.

---

### 7.3 Quantity by Category

A donut chart represents the quantity distribution among product categories.

It provides a quick visual comparison of product-category sales volume.

---

### 7.4 Quantity by Payment Mode

A donut chart analyzes quantity based on payment method.

This visualization provides insight into customer payment preferences and the distribution of transactions across payment modes.

---

### 7.5 Sales by State

A bar chart compares sales amount across states.

This provides a geographical perspective of ecommerce performance and allows users to identify regions with different levels of sales contribution.

---

### 7.6 Sales by Customer

A column chart presents sales amount at the customer level.

This helps analyze customer contribution and identify customers associated with higher sales values.

---

## 8. Interactive Features

The dashboard contains interactive slicers for:

### Quarter

Users can select a quarter to analyze performance during a particular period.

### State

Users can select a state and examine sales and related dashboard metrics for that geographical region.

The interactive filtering capability allows users to move from high-level reporting to focused analysis.

## 13. Limitations

The current dashboard focuses primarily on descriptive and diagnostic analysis.

The project does not appear to include advanced features such as:

* Customer lifetime value
* Customer segmentation
* Year-over-year growth metrics
* Profit margin percentage
* Return analysis
* Automated anomaly detection
